# toysrus

A 17:52 documentary on the fall of Toys R Us, built in Remotion. Magnates Media visual style — cinematic 3D + 2D motion graphics, narration-driven, with heavy use of visual emphasis on hard numbers and emotional beats.

## Quick start

```bash
npm install
npm run dev        # Remotion Studio at http://localhost:3000
```

See [USAGE.md](./USAGE.md) for the full build guide — asset locations, render commands, scene-timing primer, IP safety notes.

## Composition

| | |
|---|---|
| Resolution | 1920×1080 |
| Frame rate | 30 fps |
| Duration | 17:52 / 32,173 frames |
| Acts | Cold open + Act I (Empire) + Act II (Wall Street) + Act III (The Fall) |
